# ЛР 4 Рефакторинг навигации

## Что изменилось

Версия «до» — коммит `3317235` с избранными лекторами из ЛР 3. В ней уже был самописный hash-роутер. Версия «после» — коммит `a8d4c83` в ветке `lab4/routing`.

В новой версии используется `react-router-dom` 7.18.6. `BrowserRouter` подключён в `src/main.jsx`. Маршруты объявлены в `src/App.jsx` через `Routes` и `Route`. Шапка и подвал общие для всех страниц. Для меню используется `NavLink`, для остальных внутренних переходов — `Link`.

Профиль получает ID лектора через `useParams()`. Кнопка «Все лекторы» возвращает в каталог через `useNavigate()`. Для неизвестного пути и неизвестного ID выводится страница 404. Старые адреса вида `/#/lecturers/petrov` переводятся на `/lecturers/petrov`.

## Рендеры карточек

В обеих версиях временно добавлялся `console.log` в тело `LecturerCard`. Если повторять замер, можно вывести `console.log('Рендер карточки:', lecturer.id)` и считать только новые строки после каждого действия. При замере использовался dev-режим с включённым `StrictMode`. Диагностический вывод удалён из итогового кода.

| Действие | До | После |
| --- | --- | --- |
| Открытие каталога | 20 вызовов для 10 карточек | 20 вызовов для 10 карточек |
| Ввод `Python` одним действием | 2 вызова, только карточка Петрова | 2 вызова, только карточка Петрова |
| Переход из результата в профиль | 0 новых вызовов карточек | 0 новых вызовов карточек |

В dev-режиме `StrictMode` вызывает функцию компонента дважды для проверки чистоты рендера. В этом сценарии после ввода запроса остальные девять карточек не вызывались повторно. Миграция на React Router не изменила количество вызовов.

## Проверка навигации

Переходы между главной, партнёрами, каталогом и страницей «О нас» проверены в обеих версиях. Белого экрана при обычных переходах замечено не было. Исходная версия уже переключала страницы внутри приложения.

После миграции дополнительно проверены:

- Вход по прямой ссылке на профиль, перезагрузка профиля и возврат в каталог.
- Подсветка пункта «Лекторы» в профиле и переход из направления на главной в каталог с параметром `q`.
- 404 для неизвестного пути и неизвестного ID лектора.
- Сохранение избранного после перезагрузки и фильтр «Только избранные».
- Наличие основного JS-файла и выдача `index.html` на прямых маршрутах в `npm run preview`.

При размещении на статическом сервере для прямых ссылок нужно настроить выдачу `index.html` на маршрутах приложения.
