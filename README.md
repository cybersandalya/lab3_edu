# Учебная платформа

Сайт с каталогом лекторов. В каталоге можно искать по фамилии и темам, сортировать лекторов по цене и стажу, сохранять избранных и смотреть программы и тарифы.

## Стек

- React и React DOM 19.3.0
- React Router DOM 7.18.6
- Vite 8.3.1 и плагин React 6.1.1
- JavaScript, JSX и CSS
- Node.js 20.19+ в ветке 20.x или 22.12 и новее. Проверено на Node.js 24.21.0 и npm 11.19.0.

## Запуск

```bash
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Для сборки выполните `npm run build`. Результат будет в папке `dist/`.

## Структура проекта

| Путь | Что внутри |
| --- | --- |
| `src/pages/` | Страницы сайта |
| `src/components/` | Компоненты и их стили |
| `src/data/` | Данные лекторов, партнёров, меню и тексты |
| `src/main.jsx`, `src/App.jsx` | Подключение роутера, маршруты и общий интерфейс |
| `src/utils/` | Поиск, сортировка и форматирование |
| `src/styles/` | Общие стили и переменные |
| `src/config.js` | Адрес хранилища изображений |

Данные лекторов находятся в [`src/data/lecturers.js`](src/data/lecturers.js).

Изображения загружаются из Yandex Object Storage. Для запуска достаточно подключения к интернету, файл `.env` создавать не нужно. Форма записи работает в демонстрационном режиме.

## Роутинг

`BrowserRouter` подключается в [`src/main.jsx`](src/main.jsx). Маршруты объявлены в [`src/App.jsx`](src/App.jsx) через `Routes` и `Route`. Шапка и подвал общие для всех страниц.

| Адрес | Страница |
| --- | --- |
| `/` | Главная |
| `/partners` | Партнёры |
| `/about` | О нас |
| `/lecturers` | Каталог лекторов |
| `/lecturers/:id` | Профиль лектора |
| `*` | Страница 404 |

Для внутренних переходов используются `Link` и `NavLink`. В `/lecturers/petrov` профиль получает `id` через `useParams()`, а кнопка «Все лекторы» возвращает в каталог через `useNavigate()`. Адрес `/lecturers?q=Python` открывает каталог с заполненным поиском. Для неизвестного ID лектора показывается 404. Ссылки вида `/#/lecturers/petrov` перенаправляются на новые адреса.

Чтобы добавить страницу, создайте компонент в `src/pages/` и добавьте `Route` в `src/App.jsx`. Если страница нужна в главном меню, добавьте пункт в `src/data/navigation.js`.

При размещении сборки на статическом хостинге настройте выдачу `index.html` для прямых запросов к маршрутам приложения, например `/lecturers/petrov`. Vite уже обрабатывает такие запросы в `dev` и `preview`.
